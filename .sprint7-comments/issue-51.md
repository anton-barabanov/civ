### Тест-сценарии (headless; фиксация рандома по образцу run.mjs:208-217 — Math.random = () => 0 / () => 0.99)
1. Успех кражи (random→0): шпион в чужом городе → тех вора +1 из techs цели, шпион удалён, лог есть.
2. Провал (random→0.99): шпион удалён, тех нет; в мире + второй патч random→0 (вероятность войны 0.3 сработала) → declareWar вызван, resDeals/дань разорваны (заодно живучесть j).
3. Саботаж: prodStored 100 → успех 50; провал — без изменений + гибель шпиона.
4. Контрразведка: шпион владельца в городе: Math.random=0.31 → без контра был бы успех (0.6), с контра — провал (0.3); для саботажа порог 0.35/0.7.
5. Война+провал: уже воюющие — declareWar не вызывается повторно.
6. ИИ: дать espionage+gold → шпион появляется (найм), доходит до города лидера (постановка рядом), крадёт теху.
7. Совместимость с #49: миссия выполняется от currentPlayer ≠ 0; лог виден всем.

## Дизайн-ревью (архитектор) — S8-1 Военные союзы, волна 1 из 5 (#56 → #57 → #58 → #59∥#60 → #61)

Решения владельца продукта зафиксированы: карта 36×24 через #58 (тут не зависит), баланс-проход #59 — только константы (тут не зависит). Эпик #5 закрываем упрощённой моделью союза против «сделки с общим врагом» из тела issue (см. отклонения ниже).

### Ключевые решения

1. **Данные**: `S.relations[k]` расширяется до `{ war, since, lastTradeTurn, ally: false, allySince: -1, allyBrokenTurn: -99 }` (инициализация core.js:544). Союз двусторонний и общий, БЕЗ указания общего врага (упрощение против тела issue — «военный союз против X» не храним). Константы: `ALLY_PENALTY_TURNS = 20`, `ALLY_PENALTY_MULT = 1.2`, `ALLY_JOIN_STRENGTH = 0.9` (рядом с TRADE_COOLDOWN:49). Каскад союзов — глубина ровно 1 (не константа, гарантия рекурсии).
2. **API**: `isAlly(i, j)` (false при BARB_ID), `proposeAlliance(fromIdx, toIdx)`, `breakAlliance(i, j)` — headless, в экспорты и debugApi (образец — offerPeace/demandTribute).
3. **Принятие ИИ** (в proposeAlliance, только для не-человека): согласен при `relWarFactor(i, j) < 1.3` (разные госрелигии блокируют) И (`strengthOf(from) < ALLY_JOIN_STRENGTH * strengthOf(to)` — союзник слабее нас, ИЛИ общая война: ∃ j: `atWar(to, j) && atWar(from, j)`). Отказ при войне между сторонами, при действующем союзе и в окне штрафа после разрыва (`S.turn - allyBrokenTurn < ALLY_PENALTY_TURNS`). Инициативу ИИ («сам предлагает человеку») в спринт НЕ берём — backlog.
4. **Обязательства**:
   - Объявление войны СОЮЗНИКУ (по духу Civ4): в `declareWar(i, j)` — если `isAlly(i, j)`: сначала `breakAlliance` (ally=false, allyBrokenTurn=S.turn, лог «союз расторгнут»), война i→j идёт обычным порядком, автозахвата союзников жертвы НЕ происходит (союз уже разорван до каскада) и объявлять доп. войну никому не нужно.
   - Война против союзника союзника: после основного тела declareWar(i, j) — для каждого живого k≠i,j с `isAlly(k, j)` → `declareWar(k, i, /* _cascade */ true)`. Параметр `_cascade` (default false, сигнатура обратно совместима, внешние вызовы не меняются) подавляет дальнейший каскад → глубина 1. Случай «k союзник и i, и j» решается естественно: declareWar(k, i) видит isAlly(k, i) → разрыв союза + война, без каскада.
   - Мир отдельный от союзов: `makePeace` (2200) НЕ трогаем вообще — мир пары не расторгает союзы с третьими сторонами. Отклонение от тела issue («сепарный мир расторгает союз») — принято решение: союз не привязан к конкретной войне.
   - Видимость карт союзников — НЕТ (упрощение). Совместная победа — НЕТ (победа индивидуальна, checkVictory не трогаем).
   - Пропуск юнитов: фактический гейт в коде не в canEnter (209 — проверок владельца нет вообще, дороги и территория открыты), а в `reachable` (650-657: чужой город/стопка = проходимо только при войне/миссионер/шпион) и `moveUnit` (673). Решение: союзнический город проходим как свой — в reachable ветку foe добавить `isAlly(u.owner, foe)` → обычный проход (res.set), в moveUnit:673 добавить `&& !isAlly(u.owner, oc.owner)`. canEnter не меняется.
5. **Разрыв союза**: свободный (кнопка), `allyBrokenTurn = S.turn`; в `relWarFactor` (1100) в конце: множитель `ALLY_PENALTY_MULT`, пока `S.turn - allyBrokenTurn < ALLY_PENALTY_TURNS` (×1.2 на 20 ходов). Затрагивает aiAcceptsDeal/councilSupport/readyForPeace — это желаемо (разрыв портит отношения везде). Значения 20/1.2 — константы поведения, заведены здесь; #59 их тюнить НЕ будет (не входят в список кандидатов).
6. **ИИ и войны**: в aiDiplomacy подбор цели войны (2412-2427) — гвард `if (isAlly(i, target)) continue;` (одна строка, иначе союз бессмысленен). Остальное ИИ-поведение не меняем. PEACE_STRENGTH/readyForPeace — без правок.
7. **UI** (app.js showDiplo 846-856): в статусе строки отношений «🛡 союз с хода N»; кнопки «Предложить союз» (data-ally=i; disabled при войне/действующем союзе/окне штрафа) и «Расторгнуть союз» (data-breakally=i); обработчики рядом с data-war/data-peace; записи в лог через addLog. Индикатор в списке — текст в status-строке, отдельных панелей не делаем.

### Тест-сценарии (headless, в test/run.mjs; размеры через api.S.map.length — не литералами, чтобы #58 не чесал)
1. ИИ принимает союз: фикс Math.random, сила просителя < 0.9× ИИ, relWarFactor<1.3 → ally=true, allySince=turn; при разных госрелигиях (1.3) — отказ; при силе ≥ 0.9× без общей войны — отказ; при общей войне — принимает.
2. Война союзнику: declareWar разрывает союз (ally=false, allyBrokenTurn), война идёт, третьи союзники НЕ входят.
3. Каскад глубины 1: A-союз-B, C объявляет войну B → A входит (war A-C); союзник A2 союза A НЕ входит.
4. Разрыв: relWarFactor ×1.2 в окне 20 ходов, сброс после; повторное предложение в окне — отказ.
5. Пропуск: юнит в городе союзника — reachable содержит тайл, moveUnit проходит; не-союзнику (мир) — нет.
6. makePeace не трогает ally; endTurn-smoke с двумя союзами не падает; load() дефолтит ally=false.
7. aiDiplomacy не объявляет войну союзнику (фикс Math.random, серия ходов).

### Риски
- Рекурсия declareWar: гарантия — параметр _cascade + союз разрывается до каскада (циклы невозможны, глубина ≤ 2 вызова).
- Случайность ИИ в тестах — фиксировать Math.random по образцу run.mjs.
- Старые civ1_save сейвы до #58: дефолты в load() обязательны (иначе undefined.ally).
- Раздувание UI: только статус + 2 кнопки, отдельных экранов не делать.
